MY FINANCE
Family Finance Management Web Application
==========================================

1. OVERVIEW
-----------
My Finance adalah aplikasi web pencatatan dan pengelolaan keuangan keluarga.
Aplikasi mengintegrasikan pencatatan transaksi multi-akun, budgeting,
financial goals, laporan keuangan, analisis data, serta kolaborasi antar-
anggota keluarga dalam satu shared workspace.

Deployment:
- Vercel
- Supabase

GitHub:
https://github.com/adjiehf231/my_finance

- Menambah saldo destination account

- To Wallet
- Amount
- Description

Transaction type:
- income
- expense
- transfer


8. BUDGETING
------------
Budget dibuat berdasarkan:
Family + Month + Category + Limit

Contoh:
Makanan       : Rp2.000.000
Transportasi  : Rp800.000
Belanja       : Rp1.500.000
Internet      : Rp350.000

Budget menampilkan:
- Budget Limit
- Actual Spending
- Remaining Budget
- Progress Percentage
- Status

Status:
- Aman       : < 70%
- Waspada    : 70% - 90%
- Melebihi   : > 100%

Progress dihitung berdasarkan:
actual_expense / budget_limit * 100

17. SECURITY
------------
Karena My Finance menyimpan data keuangan, keamanan database menjadi
komponen utama.

Gunakan:
- Supabase Auth
- Google OAuth
- PostgreSQL Row Level Security (RLS)

Prinsip RLS:
User hanya dapat membaca atau mengubah data yang memiliki family_id
yang sama dengan family tempat user tersebut menjadi anggota.

Contoh:
User A:
family_id = ABC123

User A tidak boleh mengakses:
family_id = XYZ789

Security harus diterapkan pada database, bukan hanya frontend.

33. NET WORTH TRACKING
----------------------
My Finance should support Net Worth tracking.

Formula:

Net Worth = Total Assets - Total Liabilities

Assets:
- Cash
- Bank
- E-Wallet
- Investment
- Property
- Other Assets

Liabilities:
- Credit Card
- Loan
- Installment
- Other Debt

Example:

Total Assets       Rp75.000.000
Total Liabilities  Rp20.000.000
Net Worth          Rp55.000.000


34. DEBT / INSTALLMENT MANAGEMENT
----------------------------------
Debt and installments should be managed separately from normal expenses.

Example:

Motorcycle Loan

Remaining Period: 12 months

Recommended fields:
